# Node.js backend for MAHBUB Sports Prediction App

This is a minimal Express API for a virtual sports prediction game.

## Features

- Health check endpoint
- Live score demo endpoint
- Predict API with point deduction
- User info endpoint
- In-memory storage for demo purposes

## Install

```bash
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env` and update values if needed.
